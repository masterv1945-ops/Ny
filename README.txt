مدرسه‌ی من — بسته‌ی بازسازی رابط کاربری
========================================

در این بسته، ساختار پوسته‌ی صفحات از نو چیده شده است: صفحه‌ی ورود دو‌بخشی با میانبرهای نقش‌ها، نوار کناری یکپارچه برای مدیر و معلم، ناوبری دسکتاپ دانش‌آموز، ناوبری پنل والدین، طراحی واکنش‌گرا برای موبایل، فرم‌ها، کارت‌ها و جدول‌های تازه.

فایل‌ها
-------
index.html              صفحه‌ی ورود و مسیریابی نقش‌ها
student.html            پنل دانش‌آموز
teacher.html            پنل معلم
parent.html             پنل والدین
manager.html            پنل مدیریت
school-live.js          ماژول مشترک فعلی مدرسه
madrese-redesign.css    طراحی و چیدمان جدید
madrese-redesign.js     ساخت پوسته و ناوبری جدید روی بخش‌های عملکردی فعلی

نکته‌ی مهم درباره‌ی اطلاعات و Supabase
--------------------------------------
این بسته برای تغییر ظاهر و چیدمان طراحی شده است. شناسه‌های عناصر، فرم‌های ورود و منطق فعلی عملیات آموزشی عمداً حفظ شده‌اند تا اتصال موجود Supabase بی‌دلیل عوض نشود. پایگاه داده یا فایل‌های SQL در این بسته تغییر داده نشده‌اند.

روش جایگزینی در GitHub Pages
----------------------------
1. ابتدا از مخزن فعلی یک نسخه‌ی پشتیبان بگیر.
2. فایل‌های index.html، student.html، teacher.html، parent.html، manager.html و school-live.js موجود در ریشه‌ی مخزن را با فایل‌های هم‌نام این بسته جایگزین کن.
3. دو فایل madrese-redesign.css و madrese-redesign.js را نیز در همان ریشه‌ی مخزن بارگذاری کن.
4. فایل‌های SQL، مهاجرت‌های Supabase، تنظیمات مخزن و سایر فایل‌های پروژه را حذف نکن.
5. پس از انتشار، هر پنج صفحه را جداگانه بررسی کن؛ چون محیط این بسته به پروژه‌ی آنلاین Supabase متصل نشده، ورود واقعی، سیاست‌های RLS و ذخیره‌سازی زنده از داخل این محیط آزمایش نشده‌اند.

اگر در مخزن اصلی نام فایل مشترک به جای school-live.js چیز دیگری است، صفحه‌های parent و manager در این بسته طبق نام school-live.js به آن ارجاع می‌دهند؛ پس فایل مشترک باید با همین نام در کنار صفحه‌ها قرار بگیرد.
